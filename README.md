# Jess. Food Delivery 

Современный web-сервис доставки еды с продуманной ролевой моделью (Клиент, Курьер, Владелец ресторана, Админ). 

Стек технологий
 Backend: Python, FastAPI, SQLAlchemy
 Database: PostgreSQL
 Frontend: Jinja2, HTML, Tailwind CSS

Главные фичи:
Управление меню заведений, корзина покупок, отслеживание статусов заказов (от кухни до двери клиента) и изолированные дашборды для каждой роли.
